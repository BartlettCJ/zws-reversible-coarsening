# Interpretation guide

A compact vocabulary keeps the result honest.

- **Measurement:** a value in a checksummed result.
- **Exact/formal inference:** follows from the finite rule and declared definitions.
- **Scientific interpretation:** a mechanism compatible with, but not uniquely forced by, measurements.
- **Speculation:** a broader possibility worth considering.

Examples:

- “The rule preserved Q at every saved phase” is a measurement.
- “The local permutation preserves Q for every possible block” is an exact inference.
- “The 27.5% onset is nucleation-like” is an interpretation requiring horizon and seeded-state evidence.
- “A similar mechanism could matter in fundamental physics” is speculation.

The high-entropy labyrinths are not automatically organisms. There is no measured lineage, heredity, metabolism, self-maintained boundary, selectable fitness or conscious organisation in this extension.

The strongest relevance to *Zero Without Stasis* is narrower and real: one exact signed zero can coexist with multiple active macroscopic regimes, and an orthogonal unsigned coordinate can carry substantial reversible organisation. The exact zero constrains the world; it does not exhaust its state.
